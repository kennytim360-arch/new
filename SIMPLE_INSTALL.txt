================================================================================
                    RO/RO MONITOR - SIMPLE INSTALLATION
================================================================================

STEP 1: Run the setup script
-----------------------------

    python FINAL_SETUP.py

This will:
  - Fix all import errors
  - Verify all files are present
  - Check if dependencies are installed
  - Tell you exactly what to do next


STEP 2: Install dependencies (if needed)
-----------------------------------------

If FINAL_SETUP.py says "DEPENDENCIES NEEDED", run:

    pip install -r requirements.txt

Or if that fails, install individually:
    pip install pandas numpy yfinance dash plotly dash-bootstrap-components


STEP 3: Run the monitor
------------------------

    python main.py analyze

This will:
  ✓ Fetch REAL market data from Yahoo Finance
  ✓ Calculate regime score (0-100)
  ✓ Show 5 pillar breakdowns
  ✓ Generate CFD position recommendations
  ✓ Display any active alerts

TROUBLESHOOTING:
----------------

Error: "No module named 'pandas'"
Fix: pip install -r requirements.txt

Error: "cannot import name"
Fix: python FINAL_SETUP.py

Error: Network/timeout fetching data
Fix: Check internet connection, try again
