# 🚀 START HERE - Quick Installation

## One-Command Install

```bash
python COMPLETE_INSTALLATION.py
```

This single script will:
1. ✅ Install all missing files
2. ✅ Fix all import errors
3. ✅ Test with REAL market data
4. ✅ Verify everything works

**Takes 1-2 minutes total.**

### Step 1: Installing Data Module
Creates `roro_monitor/data/` folder and files

### Step 2: Fixing All Issues
Fixes imports and exports

### Step 3: Testing System
**Fetches real market data and calculates regime!**

You'll see:
- Master Score: 67.3/100 (example)

## Support

If you get errors, check:
1. Python version: `python --version` (need 3.8+)
2. Dependencies installed: `pip install -r requirements.txt`
3. Internet connection active
4. In correct directory (folder with `main.py`)
